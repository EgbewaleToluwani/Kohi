# Kōhī - Specialty Store


## DISCLAIMER

This website was created as a fictional concept project for portfolio and skill demonstration purposes.
The coffee store, brand, products, locations, and related content shown on this site are not real businesses and are not affiliated with any existing company.
This project was built solely to showcase my frontend development, UI/UX, and responsive web design skills.

### ☕ About The Project

Kōhī is a modern coffee store website inspired by Japanese café aesthetics and minimalist design principles. The project focuses on delivering a smooth and visually appealing user experience while demonstrating strong frontend engineering practices.

The website includes:

- Responsive landing pages
- Product showcase sections
- Interactive UI components
- Modern animations and transitions
- Mobile-first design
- Clean and scalable frontend architecture
